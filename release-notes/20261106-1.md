- New: builds with large file support (`l`), in their own PFS\2 table. They reach files above 4 GiB through the 64 bit packets of AmigaOS 4 and list the real size through the 64 bit examine packets. Builds without `l` refuse a volume they format.
- Release set: 000, 020 and 080, each with and without `l`, built with gcc 6.5, 13.4 and 16.2. vbcc, gcc 15.2 and the 030, 040, 060 and 080a builds are no longer published.
- Formatting no longer shows the file size warning.
